# AEM Front End Developer Senior II: HR job description

## IDENTIFICACIÓN DEL CARGO

- **Nombre Cargo:** AEM Front end Developer Senior II
- **Área:** Digital Experience Platforms Business Unit
- **Cargo jefe inmediato:** Technical Lead I
- **Elaborado por:** Michell Suescun
- **Aprobado por:** Diego García Bojacá
- **Fecha elaboración:** 22/07/2025

## MISIÓN

Diseñar e implementar soluciones de front end modernas, accesibles y de alto rendimiento sobre la plataforma Adobe Experience Manager (AEM), incluyendo arquitecturas tradicionales y nuevas soluciones basadas en Edge Delivery Services (EDS). Este rol tiene como objetivo acelerar la entrega de experiencias digitales consistentes, escalables y centradas en el usuario, trabajando de forma colaborativa con equipos de diseño, contenido y tecnología.

## LUGAR DE TRABAJO

Se proporcionará asistencia remota a las sucursales y dependencias de la organización, asegurando un soporte integral para todas las operaciones. En caso de ser necesario, se requerirá la presencia en la sucursal de la ciudad correspondiente para atender necesidades específicas.

## RESPONSABILIDADES CLAVES

| Qué debe hacer | Para qué lo debe hacer |
|---|---|
| Definir la arquitectura UI de proyectos AEM a gran escala. | Establecer soluciones técnicas escalables y sostenibles desde etapas tempranas del proyecto. |
| Liderar la implementación de interfaces accesibles (WCAG 2.2 AA+). | Asegurar que los productos digitales sean inclusivos y cumplan con normativas internacionales. |
| Establecer patrones reutilizables, guías de estilo y herramientas como Storybook. | Unificar el diseño, acelerar el desarrollo y facilitar la colaboración entre equipos. |
| Coordinar la optimización SEO técnico, auditorías Lighthouse y performance en EDS. | Garantizar el rendimiento óptimo, posicionamiento en buscadores y cumplimiento técnico. |
| Actuar como referente técnico ante clientes, UX y stakeholders del negocio. | Alinear expectativas técnicas con necesidades estratégicas y aportar visión desde la tecnología. |
| Desarrollar componentes complejos con HTL y Drop-ins para AEM tradicional y EDS. | Construir interfaces avanzadas y modulares, compatibles con arquitecturas híbridas. |
| Integrar APIs GraphQL y REST de forma eficiente. | Lograr una experiencia de usuario dinámica, conectada y desacoplada. |
| Implementar pruebas unitarias (por ejemplo, con Jest) y asegura la calidad del código. | Garantizar el correcto funcionamiento, reducir errores y facilitar el mantenimiento. |
| Optimizar el rendimiento de las interfaces (Core Web Vitals, lazy loading, carga diferida, bundles livianos). | Mejorar la velocidad, eficiencia y usabilidad en todos los dispositivos. |
| Participar activamente en revisiones de código y en la mentoría de perfiles junior. | Fomentar el crecimiento técnico del equipo y mantener estándares de calidad. |
| Realizar todas las actividades inherentes al cargo. | Contribuir al cumplimiento efectivo de los objetivos y propósitos establecidos para la posición. |

## CONOCIMIENTOS ESPECÍFICOS DE LA POSICIÓN

- **Años de experiencia requeridos:** 6
- **Nivel de inglés requerido:** B1

**Conocimientos técnicos requeridos para desempeñar el cargo:**

- Técnico, tecnólogo o profesional en Ingeniería de Sistemas, Ingeniería Informática, Ciencias de la Computación, Desarrollo de Software y/o carreras afines, o contar con experiencia relevante para el cargo.
- Dominio de HTML5 y CSS3, incluyendo preprocesadores como SASS o LESS.
- Conocimiento avanzado de JavaScript moderno (ES6+).
- Manejo de Git para control de versiones y flujos de trabajo colaborativos.
- Experiencia en el desarrollo de componentes con HTL (Sightly) en Adobe Experience Manager.
- Conocimiento práctico de Page Editor y Universal Editor en AEM.
- Uso de Componentes Core de AEM como base para el desarrollo de interfaces.
- Experiencia en desarrollo con React o Preact (incluyendo hooks, gestión de estado y ciclo de vida).
- Experiencia en el consumo de contenido estructurado mediante GraphQL desde Fragmentos de Contenido en AEM.
- Integración de servicios mediante REST APIs.
- Conocimientos en pruebas automatizadas utilizando herramientas como Jest, Cypress o Playwright.
- Experiencia en configuración y optimización de proyectos con Webpack o Vite.

**Conocimientos técnicos deseables para desempeñar el cargo:**

- Conocimiento en el cumplimiento, promoción de políticas y controles para garantizar la seguridad de la información, en alineación con la norma ISO/IEC 27001 y otros sistemas de gestión, procedimientos o políticas en los que la empresa pueda certificarse.
- Conocimiento en el uso de Storybook para documentar y probar componentes UI de forma aislada.
- Familiaridad con Lighthouse para auditorías de rendimiento, accesibilidad y buenas prácticas web.
- Manejo básico o experiencia en SonarQube para análisis de calidad y seguridad del código.
- Comprensión de los principios de accesibilidad digital según las normas WCAG 2.2.
- Conocimiento de los indicadores de experiencia de usuario definidos por Core Web Vitals.
- Experiencia en optimización SEO técnico y desempeño en entornos Edge Delivery Services (EDS).
- Experiencia o familiaridad con arquitecturas basadas en Micro-frontends.
- Conocimientos en Server-Side Rendering (SSR) y Static Site Generation (SSG) para mejorar performance y SEO.
- Entendimiento del uso de caching en Edge/CDN para optimizar la entrega de contenido estático o dinámico.

**Conocimientos específicos para desempeñar el cargo:**
- Comunicación efectiva: Capacidad para intercambiar ideas técnicas, funcionales de manera clara y asertiva, facilitando la toma de decisiones y la alineación de expectativas.
- Pensamiento analítico: Habilidad para identificar problemas técnicos, evaluar alternativas y proponer soluciones sostenibles y eficientes.
- Atención al detalle: Precisión al implementar diseños, accesibilidad, estándares técnicos y rendimiento de interfaces.
- Trabajo colaborativo: Disposición para integrarse en equipos multidisciplinarios y contribuir activamente al logro de objetivos comunes.
- Adaptabilidad: Capacidad para aprender nuevas tecnologías, ajustarse a cambios en el entorno técnico y enfrentar desafíos de manera proactiva.

**Certificaciones requeridas para desempeñar el rol:**

- Deberá cumplir con al menos dos certificaciones del plan de formación estipulado para el área Digital Experience Platforms Business Unit, relacionadas directamente con el ejercicio del cargo.

## AUTORIDAD

| Decisiones | Recomendaciones |
|---|---|
| • Definir la arquitectura técnica del front-end en proyectos AEM, incluyendo el uso de frameworks, estructura de componentes y lógica de presentación, asegurando consistencia, escalabilidad y mantenibilidad.<br>• Seleccionar tecnologías, frameworks y metodologías de desarrollo front-end (como React, TypeScript, Web Components, etc.), priorizando rendimiento, compatibilidad y calidad visual.<br>• Establecer lineamientos para la integración de componentes front-end con APIs y servicios back-end, definiendo contratos de datos, formatos de respuesta y manejo de errores.<br>• Tomar decisiones sobre resolución de bugs complejos o cuellos de botella en la interfaz, incluyendo refactorizaciones urgentes, optimización de carga o ajustes visuales críticos.<br>• Decidir la estrategia de asset management (imágenes, fuentes, recursos estáticos) y performance front-end (lazy loading, minificación, compresión, etc.) para garantizar tiempos de carga óptimos. | • Promover el uso de Componentes Core siempre que sea viable, para asegurar compatibilidad, mantenibilidad y alineación con las guías de Adobe.<br>• Recomendar GraphQL cuando se trabaje con Fragmentos de Contenido y se requiera eficiencia en el consumo de datos; sugerir REST en contextos más simples o con APIs externas ya existente.<br>• Sugerir SSR o SSG cuando se prioriza el rendimiento y SEO; optar por CSR en aplicaciones donde la interactividad en tiempo real lo justifique. |
