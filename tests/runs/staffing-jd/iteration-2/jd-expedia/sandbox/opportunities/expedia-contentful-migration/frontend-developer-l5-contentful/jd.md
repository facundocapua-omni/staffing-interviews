# Frontend Developer · Semi Senior Advanced (L5) · Contentful

**Location:** LATAM; remote

A frontend developer who builds pages and components for the Next.js front end, fed by Contentful, of a US-based global travel company's partner-facing websites, migrating from AEM.

## Must have

- [ ] 4 years of frontend development experience `[HR job description]`
- [ ] Has owned multiple related views, or a feature with shared state and components across them `[handbook level]`
- [ ] HTML/CSS/JS fundamentals and responsive, accessible UI development `[handbook role]`
- [ ] React with Next.js, fully decoupled from a headless CMS such as Contentful `[handbook role]` `[handbook platform]` `[Propuesta]`
- [ ] REST/GraphQL API integration `[handbook role]`
- [ ] Frontend testing (Playwright or equivalent) `[handbook role]`
- [ ] English B2 or higher `[suite rule]`

- Implement locale routing and locale-specific links `[Propuesta]`
- Keep the sites' tracking, consent and SEO behaviour on par with the current ones `[Propuesta]`

## Screening

1. "Tell me about a set of related pages or a feature with shared components that you owned. How did you structure the state and components?" A good answer describes shared components and state across views, built with React/Next.js.
2. "How did your front end get its content from a CMS or API?" A good answer names a headless CMS such as Contentful, or REST/GraphQL APIs, and handles loading and error states.
3. "How do you make a component accessible and test it?" A good answer covers WCAG basics and component or end-to-end tests with Playwright or an equivalent.
4. Check in the CV or profile: 4 years of frontend development, with React and Next.js.
5. Run part of the call in English: the candidate explains a technical topic at B2 or higher.

## Not a fit if

- Fewer than 4 years of frontend development experience
- Has built only single components from a spec, never owned a set of related views or a feature
- No production React and Next.js experience
- No experience integrating REST or GraphQL APIs
- No responsive or accessible UI work
- Writes no frontend tests
- English below B2
