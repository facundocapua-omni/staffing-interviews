# Backend Developer · Semi Senior Advanced (L5) · Contentful

**Location:** LATAM; remote

A backend developer who builds the Contentful content model, apps and migration pipeline for a US-based global travel company moving its partner-facing websites from AEM to Contentful.

## Must have

- [ ] 4 years of backend development experience `[HR job description]`
- [ ] Has owned multiple related integrations, or a content model with cross-cutting dependencies, end to end `[handbook level]`
- [ ] Server-side development fundamentals and backend testing `[handbook role]`
- [ ] Content modeling and development on Contentful: Content Management API, `contentful-cli`, Content Delivery API or GraphQL Content API `[handbook role]` `[handbook platform]`
- [ ] REST/GraphQL API design and consumption `[handbook role]`
- [ ] Building Contentful apps with the App Framework `[Propuesta]` `[hiring lead]`
- [ ] English B2 or higher `[suite rule]`

## Nice to have

- Scripted content migration from one CMS to another `[Propuesta]`
- Familiarity with AEM, the platform the content migrates from (content structure, Content Fragments) `[Propuesta]`
- Search integration with Algolia or Elasticsearch `[handbook platform]` `[hiring lead]`

## What the person will do

- Model content types for four partner-facing websites (pages, sections, blocks) with locales and fallback `[handbook role]` `[Propuesta]`
- Build the content resolution API as a Contentful app: variants by locale, tone and channel, fallback to default content, a trace record per resolution `[Propuesta]` `[hiring lead]`
- Build custom workflow and editor apps in Contentful where its configuration is not enough `[Propuesta]`
- Build and run the scripted migration pipeline: extract, transform, load and validate content, idempotently, from rehearsal to final delta `[handbook role]` `[Propuesta]`
- Write unit and integration tests for the backend logic `[handbook role]`
- Agree API contracts with the front end and deployment needs with DevOps `[handbook role]`

## Screening

1. "Describe a Contentful content model you built. How did you handle references between content types and locales?" A good answer covers content types, references, localized fields and a change made through the Content Management API or `contentful-cli`.
2. "Have you built a Contentful app? What did it do?" A good answer describes an app they built with the App Framework and how it was hosted.
3. "Tell me about an integration you owned end to end. How did you design and test it?" A good answer covers the API design, error handling and automated tests.
4. Check in the CV or profile: 4 years of backend development, with Contentful work and API integrations.
5. Run part of the call in English: the candidate explains a technical topic at B2 or higher.

## Not a fit if

- Fewer than 4 years of backend development experience
- Has only implemented single features or endpoints from a spec, never owned an integration or a content model end to end
- No hands-on Contentful development (only authoring content)
- Has never designed or consumed REST or GraphQL APIs
- Has never built a Contentful app
- Writes no backend tests
- English below B2
