# DevOps Engineer · Senior Level 1 (L6) · Contentful

**Location:** LATAM; remote

A senior DevOps engineer who builds the AWS environments, pipelines and edge routing for the new Next.js front end, fed by Contentful, of a US-based global travel company's partner-facing websites, migrating from AEM.

## Must have

- [ ] 5 years of DevOps experience `[HR job description]`
- [ ] Has owned a project's delivery architecture decisions (pipeline design, environment strategy, observability) `[handbook level]`
- [ ] CI/CD pipeline design with GitHub Actions or equivalent, on GitHub `[handbook role]` `[handbook platform]`
- [ ] Hosting a web front end on AWS: accounts, IAM, networking, WAF, Lambda, S3, SQS, DynamoDB `[handbook role]` `[handbook platform]` `[Propuesta]`
- [ ] Infrastructure as code with SST, Terraform or CDK `[Propuesta]`
- [ ] Observability with Datadog and CloudWatch `[handbook role]` `[Propuesta]`
- [ ] English B2 or higher `[suite rule]`

## Nice to have

- Akamai configuration: edge routing rules, redirects, cache purge `[Propuesta]`
- Deploying Next.js on AWS with OpenNext `[Propuesta]`
- Lighthouse checks as a pipeline gate `[Propuesta]`
- Familiarity with AEM, the platform the sites migrate from `[Propuesta]`

## What the person will do

- Define the delivery architecture: pipeline design, environment strategy, observability `[handbook level]`
- Set up development, test and production environments on the client's AWS account, as infrastructure as code `[handbook role]` `[Propuesta]`
- Build the front end's CI/CD with tests, Lighthouse and Next.js version checks `[handbook role]` `[Propuesta]`
- Build the publish path: Contentful webhook, revalidation queue, page regeneration and cache purge `[Propuesta]`
- Register the new origin behind the client's CDN and support routing each site by path and cohort, with rollback at the edge `[Propuesta]`
- Set up monitoring and support releases and incident response `[handbook role]` `[Propuesta]`
- Hand over environments, pipelines and runbooks to the client's IT and DevOps teams `[Propuesta]`

## Screening

1. "Tell me about a project whose pipelines and environments you designed. What decisions did you make, and why?" A good answer covers pipeline stages, an environment strategy and the observability they set up.
2. "Which AWS services have you provisioned for a web application, and how?" A good answer names IAM, networking, WAF, Lambda, S3, SQS or DynamoDB, provisioned with Terraform, CDK or SST.
3. "How did you monitor it?" A good answer names Datadog and CloudWatch dashboards, alerts and logs.
4. Check in the CV or profile: 5 years of DevOps, with AWS, infrastructure as code and GitHub-based CI/CD.
5. Run part of the call in English: the candidate explains a technical topic at B2 or higher.

## Not a fit if

- Fewer than 5 years of DevOps experience
- Has maintained pipelines others designed, never owned a project's delivery architecture
- No CI/CD pipeline design on GitHub Actions or an equivalent
- No hands-on AWS work for a web application
- Provisions infrastructure only by hand, with no infrastructure as code
- No experience with Datadog or CloudWatch
- English below B2
