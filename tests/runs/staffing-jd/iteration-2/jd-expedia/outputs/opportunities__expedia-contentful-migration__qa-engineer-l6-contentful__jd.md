# QA Engineer · Senior Level 1 (L6) · Contentful

**Location:** LATAM; remote

A senior QA engineer who owns the quality strategy for the migration of a US-based global travel company's partner-facing websites from AEM to Contentful and a Next.js front end.

## Must have

- [ ] 5 years of QA experience `[HR job description]`
- [ ] Has owned a project's quality architecture decisions (test pyramid, tooling, coverage strategy) `[handbook level]`
- [ ] Test strategy and planning `[handbook role]`
- [ ] End-to-end test automation with Playwright `[handbook role]`
- [ ] Performance and accessibility testing with Lighthouse CI and axe `[handbook role]`
- [ ] Component and unit testing with Jest or Vitest and Testing Library `[handbook platform]`
- [ ] English B2 or higher `[suite rule]`

## Nice to have

- Validating a content migration: counts, required fields, broken links, visual diff `[Propuesta]`
- SEO parity checks: titles, canonicals, structured data, redirects, sitemaps `[Propuesta]`
- Testing multi-locale websites `[Propuesta]`
- Familiarity with AEM, the platform the sites migrate from `[Propuesta]`

## What the person will do

- Define the project's test strategy and quality gates across the four sites `[handbook level]` `[handbook role]`
- Build and maintain the automated suites: end-to-end, accessibility and performance `[handbook role]`
- Validate every migration run and support the client's QA through the phased rollout of each site `[Propuesta]`
- Check parity with the current sites: SEO, analytics data layer and consent `[Propuesta]`
- Track and report quality metrics and regressions `[handbook role]`
- Work with Frontend and Backend on testability and bug triage `[handbook role]`

## Screening

1. "Tell me about a project whose test strategy you defined. What went at each layer of the pyramid, and which tools did you choose?" A good answer covers unit, component and end-to-end layers, with tooling they chose and why.
2. "How have you automated end-to-end, accessibility and performance tests?" A good answer names Playwright, axe and Lighthouse CI, run in a pipeline.
3. "Which tools have you used for component and unit tests on a JavaScript front end?" A good answer names Jest or Vitest with Testing Library.
4. Check in the CV or profile: 5 years of QA, with test automation and ownership of a project's QA approach.
5. Run part of the call in English: the candidate explains a test approach at B2 or higher.

## Not a fit if

- Fewer than 5 years of QA experience
- Has executed test plans others defined, never owned a project's quality strategy and tooling
- Manual testing only, no end-to-end automation with Playwright
- Has never automated performance or accessibility checks (Lighthouse CI, axe)
- No experience with Jest or Vitest and Testing Library
- English below B2
