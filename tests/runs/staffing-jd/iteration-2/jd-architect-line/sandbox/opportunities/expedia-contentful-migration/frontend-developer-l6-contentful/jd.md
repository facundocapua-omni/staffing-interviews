## Screening

1. "Tell me about a Next.js site you built on Contentful: how pages were rendered and how content changes reached the site." A good answer mentions static regeneration or SSR, the Delivery API, and revalidation on publish.
2. "Which frontend architecture decisions did you own on your last project?" A good answer mentions component structure, state management and a performance budget, and why each was chosen.
3. "How did you turn Figma designs into a component library driven by CMS content?" A good answer mentions mapping content types to components and keeping presentation out of the content.
4. "How do you make components accessible and test them?" A good answer mentions WCAG, semantic HTML, keyboard navigation, and Playwright or similar end-to-end tests.
5. Check in the CV or profile: 5+ years in software development, React and Next.js work on a headless CMS.
6. Check: English at B2 or higher, in the screening call.

## Not a fit if

- Under 5 years of software development experience.
- Weak HTML, CSS or JavaScript fundamentals, or no React experience.
- Has never built a Next.js front end on Contentful.
- Has never built responsive, accessible (WCAG) interfaces.
- Has never integrated REST or GraphQL APIs in the UI.
- Has never written frontend tests.
- Has never built a component library from designs mapped to CMS content.
- Has only implemented assigned components, never owned a project's frontend architecture decisions.
- English below B2.
