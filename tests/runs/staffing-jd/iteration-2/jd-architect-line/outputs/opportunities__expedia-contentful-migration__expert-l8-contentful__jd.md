# Expert · Senior Level 3 (L8) · Contentful

## Screening

1. "Walk me through a headless Contentful architecture you designed: the content model, the APIs and how the front end consumed it." A good answer mentions content types and references, CMA vs Delivery/Preview APIs, environments, and caching or revalidation on publish.
2. "How did you plan a CMS migration so it could be rehearsed and rolled back?" A good answer mentions a scripted, idempotent pipeline, validation on every run, a phased ramp, and redirects or routing at the edge.
3. "Tell me about a custom API or Contentful app you designed that other channels consumed." A good answer mentions the contract, fallback behaviour, performance under load, and how it was hosted and monitored.
4. "How did you get a team that did not report to you to adopt a standard or reference architecture?" A good answer mentions concrete artifacts (ADRs, reference repos, reviews) and how they handled pushback.
5. Check in the CV or profile: 11+ years in software development, a solution or software architect role, and AWS architecture with infrastructure as code.
6. Check: English at B2 or higher, in the screening call.

## Not a fit if

- Under 11 years of software development experience.
- Has only implemented features, never designed an end-to-end solution or set standards for other teams.
- Has never architected a Contentful platform.
- Has never designed a CMS migration to a headless platform.
- Has never designed a custom content API or Contentful app consumed by other channels.
- Has no hands-on React or Next.js experience.
- Has no AWS architecture experience with infrastructure as code and observability.
- Has worked without automated testing, CI/CD or code review practices.
- Cannot explain technical options to non-technical stakeholders.
