# Frontend Developer · Semi Senior Advanced (L5) · Contentful

**Location:** LATAM, remote

A frontend developer for a US-based global travel company's move from a legacy enterprise CMS to Contentful: pages, sections and blocks of one Next.js application that serves four partner-facing websites.

## Must have

- [ ] 4+ years of experience in software development `[HR job description]`
- [ ] HTML, CSS and JavaScript fundamentals, and React `[handbook role]`
- [ ] Next.js on a fully decoupled Contentful front end `[handbook platform]` `[Propuesta]`
- [ ] Responsive, accessible UI development (WCAG) `[handbook role]`
- [ ] REST/GraphQL API integration, including the Contentful Delivery API `[handbook role]` `[handbook platform]`
- [ ] Frontend testing (Playwright or equivalent) `[handbook role]`
- [ ] Has owned multiple related views, or a feature with shared state or components across them `[handbook level]`
- [ ] English B2 or higher `[suite rule]`

## Nice to have

- Building components from Figma designs, mapped to CMS content types `[Propuesta]`
- Contentful App Framework for custom editor apps `[handbook platform]` `[Propuesta]`
- Next.js static regeneration, server-side rendering and Draft Mode preview `[Propuesta]`
- Tailwind CSS `[Propuesta]`
- Multi-locale routing, hreflang and SEO parity (titles, canonicals, structured data, redirects) `[Propuesta]`
- Analytics data layer and consent integration `[Propuesta]`
- Familiarity with Adobe Experience Manager, the migration's source platform `[Propuesta]`

## What the person will do

- Build page, section and block components of the shared component library from the Figma designs, on the client's React design system `[Propuesta]`
- Connect components to Contentful content, with preview support `[handbook role]` `[Propuesta]`
- Implement locale-specific pages and links, and the tracking and consent behaviour of the current sites `[Propuesta]`
- Ensure performance, accessibility and cross-browser compatibility, with component and end-to-end tests `[handbook role]`
- Work with the senior frontend developer on structure and with backend on API contracts `[handbook role]`

## Screening

1. "Tell me about a Next.js site you built on Contentful: how did a component get its content?" A good answer mentions the Delivery or GraphQL API, content types mapped to components, and how the page was rendered.
2. "Describe a feature where several views shared state or components. What did you own?" A good answer mentions the shared pieces they designed and how they kept them consistent.
3. "How do you make a component accessible and test it?" A good answer mentions WCAG, semantic HTML, keyboard navigation, and Playwright or similar end-to-end tests.
4. Check in the CV or profile: 4+ years in software development, with React and Next.js work on a headless CMS.
5. Check: English at B2 or higher, in the screening call.

## Not a fit if

- Under 4 years of software development experience.
- Weak HTML, CSS or JavaScript fundamentals, or no React experience.
- Has never built a Next.js front end on Contentful.
- Has never built responsive, accessible (WCAG) interfaces.
- Has never integrated REST or GraphQL APIs in the UI.
- Has never written frontend tests.
- Has only built isolated components, never owned several related views or a shared feature.
- English below B2.
